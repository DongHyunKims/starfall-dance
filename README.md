# STARFALL

카메라 앞에서 오리지널 3D 댄서 NOVA를 거울처럼 따라 추는 브라우저 리듬 게임입니다.

- **댄스 모드**: NOVA의 안무를 따라 춥니다.
- **스타 슬래시 모드**: 레인을 타고 날아오는 별 조각을 화살표 방향대로 양손으로 벱니다.
- **키보드로 플레이** (스타 슬래시): 카메라 없이 `W A S D`(왼손 · 청록)와 방향키(오른손 · 금빛)로 플레이합니다.
- **곡 3개**: MOON DRIFT(쉬움 · 100 BPM), STARFALL(보통 · 124 BPM), COMET RUSH(어려움 · 140 BPM). 시작 화면에서 고릅니다.
- **1인 / 2인 플레이** (댄스 모드): 같은 카메라에 두 명이 서면 왼쪽이 P1, 오른쪽이 P2입니다.
- **내 아바타**: NOVA 옆에서 내 움직임을 따라 하는 홀로그램 아바타와 실시간 싱크 표시가 나옵니다.
- 상반신만 화면에 보여도 플레이할 수 있습니다 (카메라에서 1.5~3m).
- 카메라 없이 보려면 "데모 보기"를 누르세요.
- 빌드 과정 없이 동작하는 정적 사이트입니다 (Three.js, MediaPipe Pose는 CDN에서 불러옵니다).
- 카메라 영상은 브라우저 안에서만 처리되며 저장되거나 전송되지 않습니다.
